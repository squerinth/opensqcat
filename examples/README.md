# OpenSQCat examples

Each subfolder contains a complete example program and its catalog files. The programs use OpenSQCat from the checkout or release layout, so run them in place. In File Explorer, open the `.nvgt` file or run it with `nvgt.exe` from that folder.

- `getting-started/` shows catalog loading, a shared field and explicit error handling from the documentation guide.
- `quick-start/` shows the first catalog and translation from the repository README.
- `expressive-messages/` shows conditional text and `join` from the README.
- `per-call-fields/` shows per-request values and missing-message handling.
- `live-values/` shows a resolver for changing application state.
- `catalog-references/` shows local and cross-catalog message references.

`messages.nvgt` is the broader demonstration that combines several OpenSQCat features.
