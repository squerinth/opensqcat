# OpenSQCat documentation

In a release, this documentation is in the installable library's `docs/` folder,
alongside its [license notice](../LICENSE). Copy the complete library folder to
keep both with the source. Choose a section based on what you need:

| Section | Purpose |
| --- | --- |
| [Tutorials](tutorials/README.md) | Follow complete examples to learn how to use the library. |
| [API reference](api/README.md) | Look up public types, signatures, return values and failure contracts. |
| [Advanced developer documentation](advanced/README.md) | Understand the format, application integration and contributor verification workflow. |
