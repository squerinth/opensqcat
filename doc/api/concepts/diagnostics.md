# Diagnostics and limits

## diagnostic

The library reports errors through mutable [`diagnostic` values](../opensqcat/Classes/diagnostic/!diagnostic.md). An empty `code` means no error. Codes are:

| Code | Meaning |
| --- | --- |
| `io` | Catalog cannot be opened. |
| `encoding` | Catalog bytes are invalid UTF-8. |
| `lines` | Unsupported bare CR line ending. |
| `version` | Malformed, duplicate, optional or unsupported format-version declaration. |
| `directive` | Malformed directive name or unsupported required directive. |
| `entry` | A non-comment entry has no `=`. |
| `key` | Empty or invalid message key. |
| `duplicate` | Repeated file key after trimming. |
| `syntax` | Invalid template grammar/encoding or a compile-time template limit. |
| `argument` | Invalid catalog-name input or inferred empty name, or unsupported or invalid field name/value. |
| `catalog` | An explicitly selected or referenced catalog is absent, including a missing name passed to `set_default_catalog`. |
| `message` | Root message or evaluated reference is absent. |
| `field` | An absent field is required as output, a comparison operand or a join separator. |
| `type` | Incompatible ordered-comparison operands or a non-text join separator. |
| `provider` | A provider threw or reported success with invalid data. |
| `cycle` | An evaluated message reference forms a cycle. |
| `limit` | Catalog size or runtime evaluation/output limit. |

`catalog` identifies the containing catalog for evaluation errors and the requested catalog for missing roots. For `translator.load`, it identifies the name only when a valid, nonempty name was selected and opening the file failed or `catalog.load` rejected it for the byte limit or returned-content validation; an invalid UTF-8 name or empty inferred name fails before loading and leaves this field empty. For `translator.load_text`, failure to process or parse the supplied text records the valid supplied `catalog_name`, or the selected `default_catalog_name` when that argument is empty; an invalid UTF-8 `catalog_name` fails before loading and leaves this field empty. A missing name passed to `set_default_catalog` reports `catalog` and stores the requested name. Empty or invalid UTF-8 names passed to `set_catalog` report `argument` with a generic name-validation message and leave `catalog` empty. An empty name inferred by `load` reports `argument` with the message `unable to infer a nonempty catalog name`; invalid UTF-8 names fail name validation before loading. Empty `catalog` means anonymous or unavailable; inspect the error code to distinguish these cases. Referenced catalog failures identify the referring message and name the missing target in `message`.

`path`, `key` and one-based `line` identify the message when available. `column` is a one-based UTF-8 byte position, including the key/separator prefix for file syntax and evaluation errors. Zero means unavailable. A missing referenced message identifies the referring message; a missing root identifies the requested key without a column. Version/directive errors identify their physical line and the one-based byte column of the `!` marker; `key` is empty. Field-argument diagnostics identify the field name in `message`. Catalog-name argument diagnostics may use a generic validation message; `load` with an empty inferred name reports `unable to infer a nonempty catalog name`.

Diagnostics contain identifiers and reasons, not supplied field values or provider exception text. They are returned to the caller; the library does not log them or send them to an output service.

## Limits

The implementation enforces these bounds:

| Resource | Limit |
| --- | --- |
| Catalog input | 16 MiB of UTF-8 bytes, including BOM and comments. |
| One template source | 1 MiB. |
| Parsed nodes per template | 32,768. |
| Expression parse/evaluation nesting | 64 depth units. |
| Active referenced messages | 32, including a root catalog message. |
| Evaluation steps | 65,536 per formatting operation. |
| Cumulative generated text | 1 MiB per formatting operation. |

Nesting counts internal expression traversal, not just visible parentheses. Generated-text accounting includes intermediate reference/join results as well as their insertion into enclosing messages; a composition-heavy message may reach the cumulative bound before its final text reaches 1 MiB. References and fields share operation budgets. There are no partial successful results on exhaustion.

By default, counters belong to one operation. Passing a shared [`evaluation_budget`](../opensqcat/Classes/evaluation_budget/!evaluation_budget.md) accumulates steps and generated bytes across all operations using it. Depth and active-reference limits remain per operation.

These are implementation bounds for this version, not configurable options or limits on application/provider execution. Integers retain 64-bit precision; real numbers use double precision; see [numeric semantics](../../advanced/format.md#numeric-values).
