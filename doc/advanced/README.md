# Advanced developer documentation

These documents explain format rules, integration decisions and library
development. They are separate from the step-by-step [tutorials](../tutorials/README.md)
and the public [API reference](../api/README.md).

- [Application integration](integration.md): catalog selection, field precedence,
  error handling and evaluation budgets.
- [SQCat 1 specification](format.md): encoding, declarations, directives,
  expression grammar and numeric semantics.
- [Library development](development.md): source layout, latest-NVGT testing,
  verification and local package checks for contributors.
